# Travelix — Travel Landing Page
Self-initiated portfolio concept (Project 04). Plain HTML5, CSS3 and JavaScript, no build step. Responsive from 360px phones to wide desktops.

## Run
Open `index.html`, or `npx serve .`

## Structure
- `index.html` — markup and SVG icon sprite
- `css/styles.css` — tokens, components, responsive rules (mobile first)
- `js/main.js` — mobile menu, search tabs and filter, favorites, login dialog
- `assets/images/` — hero backgrounds and destination images cropped from the supplied mockups

## Notes
Login is a front-end demo. Destinations, prices, offer code and review are sample concept content for a fictional brand.
